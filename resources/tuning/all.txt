# Every tunable the game registers, at the value the code gives it.
#
# A line is `key value`. A # starts a comment and is ignored. Bools are 0 or 1.
# An enum is its integer, names in order in the comment. A colour is r g b, or
# r g b a, each 0 to 1. A vector is its components in order.
#
# Loading a set (debug panel, Tuning) puts every variable back to the code's
# default, then applies the file. This file is those defaults, so loading it
# matches the panel's Defaults. The panel's Save writes only what differs from
# the code, and drops these comments -- saving over this file from the panel
# would replace it with a short one.
#
# The key is the Group's prefix plus the name in that Group. Each section names
# the file that registers it, which is where the variable lives and is read.
